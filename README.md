# Коментар Закона о заштити података о личности

Коментар српског прописа: **Закон о заштити података о личности** („Службени гласник РС”, број 87/2018). Обухвата **102 јединице** (чланове 1–102) у 5 поглавља коментара; уз сваки члан дат је дословни текст одредбе и коментар.

Стање прописа према: редакцијски пречишћен текст Правно-информационог система Републике Србије, у коме је као једини број „Службеног гласника” наведен број 87/2018, дакле изворни текст закона без накнадних измена (текст преузет 1. октобра 2026).

## Садржај

Види [INDEX.md](INDEX.md). Опис метода у [00-uvod.md](00-uvod.md).

1. Основне одредбе и начела (чл. 1–20)
2. Права лица на које се подаци односе (чл. 21–40)
3. Руковалац и обрађивач (чл. 41–62)
4. Пренос података у друге државе и међународне организације; Повереник (чл. 63–81)
5. Правна средства, посебни случајеви обраде, казнене, прелазне и завршне одредбе (чл. 82–102)
